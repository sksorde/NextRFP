# BIG PICTURE — WHAT THIS BACKEND IS

Before going line-by-line, understand the whole system first.

This backend is an **AI-powered RFP/Bid Review System**.

It does this:

1. User uploads:

   * RFP document
   * Vendor response/proposal

2. Backend extracts text from files

3. AI checks:

   * Is requirement answered?
   * Is response compliant?
   * Is proposal strong?

4. RAG system searches knowledge base

5. Shipley scoring engine scores proposal quality

6. Results are returned to frontend

---

```python
from fastapi.middleware.cors import CORSMiddleware
```

Imports CORS middleware.

Middleware = software layer sitting between request and response.

CORS solves browser security issue.

Without CORS:
Frontend cannot call backend from another port/domain.

Example:

* frontend → localhost:5173
* backend → localhost:8000

Browser blocks this unless CORS enabled.
